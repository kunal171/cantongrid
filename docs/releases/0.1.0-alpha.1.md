# CantonGrid 0.1.0-alpha.1

Status: source prerelease candidate. This release covers reference ingestion,
query foundations and developer/security tooling. It does not complete the live
Phase 3 pipeline or claim production readiness.

## Included

- Strict Rust project configuration, exact tagged values and deterministic lifecycle fixtures.
- Owned local PostgreSQL state/history/checkpoint/outbox transactions, recovery and writer exclusion.
- Durable fixture index/status/query workflows and explicit destination initialization.
- Shared SQL reads that apply caller/source visibility before totals and keyset pages,
  with source-lease rechecks and conjunctive lifecycle dependencies.
- Read-only PQS schema-041 inspection, machine-readable uncertainty/pruning reasons
  and retained-window consistency verification.
- Nodejumper SDK v0.3.2 row compatibility evaluated against installed Scribe 3.5.4;
  no SDK runtime dependency adopted.
- Pinned security CI: RustSec, dependency license/source policy, full-history and
  eligible-tree secret scanning with redaction, and GitHub Actions linting.
- Contributor guide, PR template, security-reporting guidance, version/notice/license
  consistency checks, Apache-2.0 license and workspace prerelease versioning.

## Verification

Local checks: 49 Rust tests (including owned-Postgres and existing LocalNet source
checks), 11 Python tests, formatting, Clippy, YAML/link checks and security tooling.
Remote CI results are recorded on the release PR; source-dependent LocalNet checks
are explicitly separate from credential-free CI.

The retained source interval 80→943 reconciled 11 baseline rows + 115 creates −
116 archives = 10 active rows, with zero missing/unexpected identities. This is
historical retained-window evidence, not a controlled concurrent handoff proof.
The SDK probe decoded 3 create/3 archive rows and 11 historical active rows, with
no payload/party output or ledger writes.

## Limits and compatibility

- Real source-grant verification, caller token authentication, REST/GraphQL and the
  live indexing worker remain incomplete. Fixture grants are simulated.
- The schema-041 archive interface omits witnesses. Archive authorization/current
  grants, dynamic metadata, handoff/pagination and retention remain live gates.
- Raw backend page keys are not public API cursors; transport-level scope/integrity
  protection is required before exposure.
- Reference ingestion retains its explicit 256-batch/16-MiB journal, 1000-event/
  1-MiB batch limits and loopback-only database transport.
- Existing project format version 1 and destination migration 001 remain unchanged.
  Rust workspace version is independent of configuration/schema versions.
- Outcomia has synthetic and artifact-validation evidence, not actual live Rust
  indexing proof. Additional tracks, generated business models and SSE stay deferred.
- Source distribution only; binary packaging and third-party notice bundling require
  a separate reviewed release workflow. Cargo packages remain non-publishable.

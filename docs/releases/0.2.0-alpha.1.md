# CantonGrid 0.2.0-alpha.1

Published [source prerelease](https://github.com/kunal171/cantongrid/releases/tag/v0.2.0-alpha.1). The evidence below covers LocalNet, not production.

This release implements the Phase 3 LocalNet contracts profile: read-only PQS
snapshot/update ingestion, owned PostgreSQL lifecycle/history/checkpoint/outbox,
and generic authenticated REST/GraphQL. Both actual Outcomia and unrelated
Visibility examples use the same production engine and APIs.

See [runtime configuration and limits](../guide/localnet-source.md) and the exact
[acceptance evidence](../verification.md). History is snapshot-forward
partial; raw JSON preserves exact values without generated Daml/business types.
Source/caller authorization, scoped cursors, source outages, local revocation and
restart/transaction recovery have explicit controls.

Compatibility: package version 0.2.0-alpha.1, fixture/runtime formats 1, immutable
owned migration 001 plus new checksummed migration 002. Run explicit destination
initialization before opening existing stores. Live plan changes conflict with
old definitions and require a reviewed new generation; fixture reference behavior
and limits remain intact.

Loopback-only LocalNet, default identity provider and exact template projections
are the supported profile. No Scan, remote/TLS, generated model engine, SSE,
Outcomia deployment to devnet, funded assets/trades or production readiness claim.
Binary publication still requires reproducible packaging and upstream notices,
including the approved dependencies' BSD-2/BSD-3 notices. Cargo publication remains
disabled. Release CI passed on PR #5 and its merge commit.

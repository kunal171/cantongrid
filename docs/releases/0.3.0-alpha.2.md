# CantonGrid 0.3.0-alpha.2

[Source prerelease](https://github.com/kunal171/cantongrid/releases/tag/v0.3.0-alpha.2).
This release adds a runnable Daml LocalNet PoC and generated model queries/client types.

## Changes

- Generate TypeScript transport interfaces and GraphQL SDL from reviewed model declarations.
- Serve authenticated typed model queries at `/models/graphql`, with canonical visibility before counts/pages and revision-scoped cursors.
- Add the standalone Draft/Open/Resolved Daml contract, DAR deployment/transaction runner, local viewer and sanitized evidence under `examples/poc`.
- Document repeat runs, exact values, privacy, revocation and indexer recovery.

Follow the [PoC guide](../guide/poc.md). The maintained example is on
[main](https://github.com/kunal171/cantongrid/tree/main/examples/poc); check out
`v0.3.0-alpha.2` to reproduce this release.

## Verification

57 credential-free Rust tests, 45 owned-PostgreSQL checks and 15 Python tests
passed. Formatting, Clippy, security and release checks passed. Two complete
LocalNet runs matched seven initial and thirteen accumulated event identities,
including party privacy, exact values, cursor isolation, caller revocation,
offline catch-up and restart without duplicates. Generated TypeScript compiled;
Chromium rendered the local viewer. PR #11 and its merge commit passed CI.
See [verification](../verification.md) and the
[sanitized artifact](https://github.com/kunal171/cantongrid/blob/v0.3.0-alpha.2/examples/poc/evidence.json).
The artifact retains its original prerelease test metadata.

## Compatibility

No new destination migration or external runtime dependency since 0.3.0-alpha.1.
Fresh/older destinations still need explicit `storage init` through migration 005.
Existing `/graphql` continues to serve generic contracts/history; generated model
queries use `/models/graphql`. Financial Int64/Numeric values remain strings in
GraphQL/TypeScript. Document formats remain version 1. No schema/API changes are
introduced by this release-notes update.

## Limits

The tested profile is loopback-only Canton 3.5.7 with Scribe 3.5.4/schema041.
Types are generated from model declarations, not arbitrary DAR schemas. The
viewer uses local fixture identities; the contract has no custody or trading.
History is snapshot-forward partial. Model queries support at most 25 rows/page,
two model resolvers/operation and a 2 MiB response. Existing backfill/work limits
remain. Advanced model filtering, staged rebuilds, durable streams, remote/TLS,
devnet and production acceptance remain later work. This is a source prerelease;
prebuilt binaries and Cargo publication are not included.

# CantonGrid 0.3.0-alpha.1

[Source prerelease](https://github.com/kunal171/cantongrid/releases/tag/v0.3.0-alpha.1).
This alpha delivers the model storage/lifecycle subset of Phase 4.

## Changes

- Declarative typed fields, filters and checked exact arithmetic; offline validation, preview and SQL planning.
- Immutable model registry and guarded installation of private PostgreSQL tables.
- `models bind` with current source checks, bounded atomic backfill, expected-revision promotion and rollback.
- Live creation/archive projections in the canonical history/outbox/checkpoint transaction.
- Outcomia and unrelated Visibility examples; developer guide and pinned Rust toolchain.

## Compatibility

Run `cantongrid storage init --database-env CANTONGRID_DESTINATION_URL` before
opening an older destination. This release adds migrations 003–005; applied
migrations 001–002 are unchanged. Migration 005 also leaves 003–004 unchanged.
Older binaries reject unknown migration sets; downgrade needs a reviewed plan.
Fixture/runtime/model document formats remain version 1. Model bindings leave
source plan/checkpoint identity unchanged. No new runtime dependencies were added
for live model projections.

## Verification

56 credential-free Rust tests, 44 owned-PostgreSQL checks and 13 Python helper
tests passed, along with formatting, Clippy, security and release checks.
Projection tests use synthetic source authority, not live Canton. The earlier
0.2 LocalNet ingestion/API acceptance remains separate evidence. Three
source-dependent tests were not rerun for this release. See [verification](../verification.md).

## Limits

Atomic backfill/cleanup is capped at 128 rows, with an 8 MiB work budget and at
most 16 bindings per stream. Larger staged rebuilds, generated model queries,
revision-bound model cursors and actual LocalNet model lifecycle acceptance are
still pending. Snapshot-forward coverage does not recover pre-snapshot history.
Durable streams, remote/TLS, devnet and production acceptance remain outside this
release. Binary packaging and Cargo publication are not included.

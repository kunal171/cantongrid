# CantonGrid 0.3.0-alpha.4

[Source prerelease](https://github.com/kunal171/cantongrid/releases/tag/v0.3.0-alpha.4).
This release adds exact model filtering, native sorting and authenticated model
discovery through REST and GraphQL, with real Outcomia application acceptance.

## Changes

- Add `eq`/`ne`, numeric ranges and optional-field null predicates, with exact string arguments and at most eight ANDed predicates.
- Sort one output field with native PostgreSQL types, nulls last and contract-ID tie breaking.
- Bind pagination to normalized filters, sorting, model revision, namespace, principal and source/caller authorization.
- Discover models at `GET /v1/models` or `GET /v1/models/{namespace}/{name}`; query at `POST /v1/models/{namespace}/{name}/query` or `/models/graphql`.
- Generate GraphQL filter/sort inputs and TypeScript query interfaces from model declarations.
- Extend the LocalNet PoC and actual Outcomia runner with privacy, revision, recovery and exact-value controls.
- Include the source-only crate packaging checks introduced after alpha.2.

Examples: [API](../guide/api.md), [PoC](../guide/poc.md), [Outcomia](../guide/outcomia.md).

## Verification

Two standalone LocalNet runs passed 54 model page sequences each. The expanded
Outcomia run passed 60 sequences, matched 25 submitted create/archive identities
and seven active records, and verified caller revocation plus optional-field
promotion/rollback. Exporter outage/recovery was verified in the standalone PoC.
Generated TypeScript compiled. Nineteen development-helper and four PoC helper
tests pass. The PR's CI covers Rust, owned PostgreSQL, source packaging and security.
See [recorded verification](../verification.md) for tested commits and scope.

## Compatibility and limits

Restart alpha.2 model pagination: older model cursors are invalid. Exact financial
values remain strings. No destination migration, automatic indexes or new external
runtime dependency is added. Initialize destinations explicitly through migration 005.

This is a GitHub source prerelease. Only the alpha.3 core crate has been published
on crates.io; the CLI must be built from source. No binaries or new crate uploads
are included. The tested profile is Canton 3.5.7, Scribe 3.5.4/schema041 and owned
PostgreSQL 14.25 on disposable LocalNet, with snapshot-forward partial history.
Staged large backfills, joins/aggregates, durable streams, funded trading projection
acceptance and remote/devnet/production verification remain pending. Phase 4 is
still in progress.

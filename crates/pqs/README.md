# cantongrid-pqs

Read-only Participant Query Store inspection, retained-window reconciliation and source coverage checks. Source history may be partial; SQL access is not caller authorization.

## Usage

```toml
[dependencies]
cantongrid-pqs = "=0.3.0-alpha.2"
```

[Library modules and examples](https://github.com/kunal171/cantongrid/tree/v0.3.0-alpha.2/crates/pqs/src) describe the API available in this version.

## Release scope

This is the historical 0.3.0-alpha.2 release, packaged for crates.io. Packaging adds
crate-local assets and metadata; the original source release remains unchanged.
Prefer the latest release for new integrations. APIs are alpha and may change.

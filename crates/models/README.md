# cantongrid-models

Declarative contract projection definitions, exact typed evaluation and SQL schema planning. Definitions do not grant source or caller access.

## Usage

```toml
[dependencies]
cantongrid-models = "=0.3.0-alpha.1"
```

[Library modules and examples](https://github.com/kunal171/cantongrid/tree/v0.3.0-alpha.1/crates/models/src) describe the API available in this version.

## Release scope

This is the historical 0.3.0-alpha.1 release, packaged for crates.io. Packaging adds
crate-local assets and metadata; the original source release remains unchanged.
Prefer the latest release for new integrations. APIs are alpha and may change.

# cantongrid-storage

Owned PostgreSQL lifecycle persistence and durable replay checkpoints. Apply destination migrations explicitly and never target an upstream PQS database.

## Usage

```toml
[dependencies]
cantongrid-storage = "=0.3.0-alpha.2"
```

[Library modules and examples](https://github.com/kunal171/cantongrid/tree/v0.3.0-alpha.2/crates/storage/src) describe the API available in this version.

## Release scope

This is the historical 0.3.0-alpha.2 release, packaged for crates.io. Packaging adds
crate-local assets and metadata; the original source release remains unchanged.
Prefer the latest release for new integrations. APIs are alpha and may change.

# cantongrid-metadata

Offline, bounded DAR/DALF signature extraction for CantonGrid. Metadata does not
authorize access, prove deployment, validate contract execution or apply migrations.

```toml
[dependencies]
cantongrid-metadata = "=0.4.0-alpha.2"
```

The supported format, limits and command are documented in the repository guide.
This development version is unreleased; use a source checkout until publication.

# cantongrid-runtime

Authorized PQS ingestion and authenticated REST/GraphQL orchestration with owned PostgreSQL persistence. Runtime configuration and source credentials are required.

## Usage

```toml
[dependencies]
cantongrid-runtime = "=0.2.0-alpha.1"
```

[Library modules and examples](https://github.com/kunal171/cantongrid/tree/v0.2.0-alpha.1/crates/runtime/src) describe the API available in this version.

## Release scope

This is the historical 0.2.0-alpha.1 release, packaged for crates.io. Packaging adds
crate-local assets and metadata; the original source release remains unchanged.
Prefer the latest release for new integrations. APIs are alpha and may change.

# cantongrid-core

Source-neutral exact values, configuration, contract lifecycle and visibility policy primitives. This library performs no network or database access.

## Usage

```toml
[dependencies]
cantongrid-core = "=0.3.0-alpha.4"
```

[Library modules and examples](https://github.com/kunal171/cantongrid/tree/v0.3.0-alpha.4/crates/core/src) describe the API available in this version.

## Release scope

This is the historical 0.3.0-alpha.4 release, packaged for crates.io. Packaging adds
crate-local assets and metadata; the original source release remains unchanged.
Prefer the latest release for new integrations. APIs are alpha and may change.
